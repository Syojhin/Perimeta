## ⚡ Game Premise & Features

In **PERIMETA**, you defend the inner sanctum core from multi-directional assault tracks (North, South, East, West). Enemies navigate serpentine perimeter vectors with distinct abilities—ranging from phase-cloaking infiltrators to shielded support drones and titanic monolith bosses.

- **Neon Vector CRT Matrix Aesthetic**: Glowing HDR line visuals, chromatic aberration, scanlines, and screen-shake impact feel.
- **Dynamic 8-Track Procedural Synthwave Soundtrack**: Adaptive multi-track audio crossfades dynamically as waves escalate.
- **Elemental Reaction Matrix**: Combine Pyro, Cryo, and Electro damage to trigger devastating status combos.
- **DAG Meta-Progression Skill Tree**: Permanent upgrades unlockable with Meta-Cores collected across runs.
- **Bilingual Interface**: Full real-time French and English localization switchable on the fly.
- **Endless Mode**: Test your defensive architecture against infinite scaling waves after conquering Sector 01.

## 💥 Elemental Reaction Matrix

Inflicting multiple elemental statuses on targets triggers volatile reactions:

```
                  ┌──────────────┐
                  │     PYRO     │
                  └──────┬───────┘
                         │
           Melt (2.0x)   │   Overload (AoE Blast)
                 ┌───────┴───────┐
                 │               │
        ┌────────┴─────┐   ┌─────┴────────┐
        │     CRYO     │   │   ELECTRO    │
        └──────────────┘   └──────────────┘
                 │               │
                 └───────┬───────┘
                         │
               Superconduct (1.5x + Armor Shred)
```

- **Melt (Pyro + Cryo)**: Instantly consumes freeze/burn for a **2.0x massive damage multiplier**.
- **Superconduct (Cryo + Electro)**: Inflicts **1.5x damage** and releases an electromagnetic wave that reduces enemy armor across the radius.
- **Overload (Pyro + Electro)**: Triggers a high-potency kinetic shockwave causing AoE damage and stagger.
- **Elemental Resonances**: Deploying matching elemental towers activates passive grid bonuses (e.g. Cryo Frost Aura, Electro Chain Arcs, Pyro Thermal Burn).
